# 🛍️ همفروش (Hamfroosh)

### پلتفرم هوشمند فروش اجتماعی از طریق تلگرام

*A modern AI-powered social commerce platform built on Telegram*

---

</div>

## 🌐 درباره پروژه / About

**همفروش** یک پلتفرم SaaS پیشرفته است که به کسب‌وکارهای ایرانی امکان می‌دهد مستقیماً از طریق تلگرام، فروشگاه آنلاین راه‌اندازی کنند — بدون نیاز به دانش فنی.

**Hamfroosh** is an advanced SaaS platform that enables Iranian businesses to launch fully-featured online stores directly through Telegram — no technical knowledge required.

---

## ✨ قابلیت‌های کلیدی / Key Features

| Feature | Description |
|---------|-------------|
| 🤖 **تلگرام‌بات هوشمند** | ربات تلگرام مجهز به هوش مصنوعی برای مدیریت فروشگاه |
| 🛒 **فروشگاه یکپارچه** | مدیریت کامل محصولات، تصاویر، و موجودی از داشبورد |
| 💳 **پرداخت آنلاین** | یکپارچه‌سازی کامل با درگاه زرین‌پال |
| 🧠 **مشاور AI** | مشاور هوش مصنوعی برای تحلیل فروش و پیشنهادات بهبود |
| 📊 **داشبورد مدیریتی** | پنل مدیریت real-time با آمار فروش و نمودارهای تحلیلی |
| 🔐 **سیستم اشتراک** | پلن‌های اشتراکی چند سطحی برای صاحبان فروشگاه |
| 📦 **مدیریت سفارشات** | پیگیری سفارش، وضعیت، و ارسال فاکتور خودکار |
| 🌍 **چندزبانه** | پشتیبانی کامل از فارسی و زبان راست‌به‌چپ (RTL) |

## 🏗️ معماری فنی / Tech Stack

```
Frontend:     Next.js 15 (App Router) + TypeScript + Tailwind CSS
Backend:      Next.js API Routes + Prisma ORM
Database:     PostgreSQL 16 + pgvector (for AI embeddings)
Bot:          Telegram Bot API (Webhook mode)
AI:           AvalAI (OpenAI-compatible) — embeddings + chat
Payments:     ZarinPal Gateway
Infrastructure: Docker + Nginx + Certbot (Let's Encrypt)
```
